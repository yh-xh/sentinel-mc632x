# 截图与演示素材

把下面这些图片放到本目录，README 与比赛文章会引用它们：

| 文件名 | 内容建议 |
| --- | --- |
| `dashboard.png` | 看板首页：双路预览 + 状态 + 事件时间线 |
| `event.png` | 事件时间线：一条完整事件（AI 图 / 原图 / 视频入口） |
| `record.png` | 录制卡片：30 秒快捷录制 + 定时录制 |
| `report.png` | 人流量报告页 |
| `xiaozhi.png` | 小智播报时的实拍或串口日志 |
| `device.png` | MC632X 双摄板 + AtomS3R 实机图 |

建议：

- 宽度 1200–1600 px，PNG/JPG 均可；
- 截图里如果出现真实姓名、手机号、住址，请先打码；
- 演示视频建议按“布防 → 有人经过 → 事件存证 → 录像 → 报告 → 小智播报”的顺序录制。
