## 烧录

先确认 u-boot 的 bootcmd：

```text
pri bootcmd
```

- 看到 `sf read 40000000 0x120000 ...`：烧 **.bin**
- 看到 `sf read 40000000 0x120010 ...`：烧 **.img**

### 写 Flash

```text
tftp 40000000 sentinel_20261031_1157_9295ba47.bin
sf probe 0
sf erase 0x120000 0x300000
sf write 40000000 0x120000 0x300000
reset
```

（`.img` 版本把第一行换成对应的 img 文件名，写入地址同样是 `0x120000`。）

### 临时启动（不写 Flash）

```text
tftp 40000000 sentinel_20261031_1157_9295ba47.bin
go 40000000
```

## 烧录后

1. 串口应看到 `SENTINEL` 初始化日志（`[rec] ready`、`[osd_web] ...`）；
2. 浏览器打开 `http://<板子IP>:8080/`，能看到双路预览、事件时间线、录制卡片；
3. 小智固件不包含在本目录，需要按 [`../docs/使用说明.md`](../docs/使用说明.md) 第 8 节编译并烧录到 AtomS3R；
4. SD 卡需为 FAT32，插卡后自动挂载到 `/mnt`。
