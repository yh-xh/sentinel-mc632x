# SENTINEL 演示视频拍摄脚本

> 目标：2 分 30 秒 – 3 分钟，1080p，16:9，B 站可投；同时截一版 60 秒竖屏短片（可选）。

## 一、拍摄前准备（逐项打勾）

- [ ] SD 卡 FAT32、剩余空间充足；是否需要清空旧事件/统计（看板“清零今日”）
- [ ] 网页时间已同步（右上角时间与电脑一致）
- [ ] 布防状态、叠加开关、录像状态都恢复到演示起点
- [ ] 小智已配网、能访问板子；先手动触发一次“让小智播报”，确认喇叭正常
- [ ] 准备一名“路人”，深色衣服，走位路线固定；地面用胶带标出绊线位置
- [ ] 灯光：正面补光，避免窗户逆光；LCD 不要过曝
- [ ] 录屏：OBS 1080p 30fps，浏览器 100% 缩放、全屏、隐藏书签栏
- [ ] 收音：旁白单独录（手机/领夹麦），现场只保留环境音
- [ ] 关闭电脑/手机通知、休眠、自动更新
- [ ] 先完整彩排 2 遍，正式拍至少 2 条备用

## 四、旁白稿（约 2 分 30 秒）

> 建议单独录音，语速 200–220 字/分钟，留 0.3 秒停顿。

“凌晨两点，一间无人小店，卷帘门外传来脚步声。店里没有人，老板在家里睡觉。

SENTINEL，一套完全跑在本地、不依赖公网的双摄边缘 AI 安防系统。

左边是 AI 机位，负责人形检测和绊线；右边是副机位，提供另一个视角的近景画面。

点击布防，有人经过绊线，事件立刻出现：AI 机位的带框图、副机位的同时刻画面，以及前后各五秒的短视频。

临时需要记录，点一下“录制三十秒”，到点自动停止，并生成人流量报告：进入多少人、离开多少人、峰值多少人。

报告页点“让小智播报”，小智用本地语音片段把结果念出来，不依赖云端 TTS。

整套系统不依赖公网：检测、存证、录像、报告都在板端完成，数据只存在店里的 SD 卡上。

这就是 SENTINEL——让无人小店在深夜里也有人守着，在清晨有人汇报。”

## 五、拍摄技巧

1. **先录屏、后实拍**：网页操作容易重来，先保证录屏素材完整；实拍补空镜和动作。
2. **鼠标慢一点**：点击前停顿 0.5 秒，点击后停 1 秒，后期好剪。
3. **多拍特写**：LCD 上的检测框、AtomS3R 的“说话”表情、SD 卡写入指示灯，都是好素材。
4. **避免拍到隐私**：画面里不要出现真实姓名、手机号、住址；演示人员戴帽子/背对镜头均可。
5. **断网演示要预演**：拔 WAN 前确认局域网仍在；小智只做“报告播报”，不要现场做语音问答（对话依赖云）。
6. **声音优先**：画面可以补拍，声音难补；旁白单独录，环境音压低。

## 六、后期剪辑

- 统一 1080p 30fps，H.264，码率 8–12 Mbps；
- 关键点击加圆圈/箭头高亮，事件出现时加 0.5 秒放大；
- 30 秒倒计时可 8× 加速，但保留“开始”和“到点停止”两秒；
- 全程中文字幕，专有名词统一：AI 机位、副机位、绊线、周界、人流量报告；
- BGM 音量压到旁白的 15% 以下，选无版权音乐；
- 导出后检查：时长 2:30–3:00、文件 < 100MB（放 GitHub）或直接传 B 站。

## 七、备选与风险

| 风险 | 应对 |
| --- | --- |
| 绊线没触发 | 调整走位/绊线位置；开启测试模式（冷却 300ms）再拍；多拍几条 |
| 小智不播报 | 先点一次报告播报确认；检查 `MCB_BASE_URL`、Wi-Fi；备一条只拍小智开口的近景 |
| SD 卡异常 | 换正牌 Class10 卡；拍摄前跑一次 30 秒录制确认 |
| 断网演示失败 | 该镜头标记为可选，正片可不放；文档里已有离线说明 |
| 现场噪声 | 旁白后期录；实拍只保留动作 |
